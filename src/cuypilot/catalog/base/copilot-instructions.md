## Team conventions (managed by cuypilot — edit outside this block)

- Always respond in the same language the user writes in (Spanish if the user writes in Spanish).
  Keep code, identifiers and technical terms in English unless the project already uses Spanish.
- Prefer the simplest solution that works well (KISS) and do not build for hypothetical requirements (YAGNI).
- Do not invent APIs, files or results. If something is uncertain, say so and verify it first.
